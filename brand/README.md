# tparquet brand

The mark is six planks that get narrower and lighter from left to right: Parquet columns,
compressed.

## Colors

| | Hex |
|---|---|
| Cobalt (primary) | `#2F5BFF` |
| Plank shades, wide to narrow | `#2140B3` `#2F5BFF` `#5D7FFF` `#86A0FF` `#ACBDFF` `#CBD6FF` |
| Ink | `#16181D` |
| Paper | `#FAFAFC` |

## Type

The wordmark is [Inter Tight](https://fonts.google.com/specimen/Inter+Tight) Bold, tracked
-0.035 em, converted to outlines so it renders the same without the font installed. Inter Tight
is under the SIL Open Font License.

Keep the planks' proportions and order, and don't recolor the wordmark beyond ink and paper.
